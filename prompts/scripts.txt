Generate a HIGH-RETENTION Islamic YouTube Shorts script.

------------------------------------------------------------
CORE OBJECTIVE
------------------------------------------------------------

The script must:
- feel personal and confronting
- escalate emotion continuously
- hold attention until the last second
- force replay (loop naturally and seemlessly)

------------------------------------------------------------
HARD CONSTRAINTS
------------------------------------------------------------

- Under 25 seconds
- Every line must add tension (no filler)
- No generic reminders
- No repeating obvious advice

If any line feels predictable → rewrite

------------------------------------------------------------
VOICE DELIVERY (CRITICAL)
------------------------------------------------------------

- 5–9 words per line
- each line = one punch
- natural speech only
- strong pauses using line breaks

------------------------------------------------------------
EMOTIONAL ENGINE (MANDATORY)
------------------------------------------------------------

The script must:
1. Expose a hidden flaw or behaviour
2. Escalate discomfort
3. Create internal conflict

Use:
- doubt
- guilt (controlled, not overwhelming)
- self-awareness
- tension
-revealing of something not know if possible

------------------------------------------------------------
STRUCTURE
------------------------------------------------------------

1. HOOK
   - immediate confrontation
   - no warm-up

2. ESCALATION
   - reveal behaviour/thought pattern
   - increase emotional pressure

3. TURN
   - unexpected insight OR uncomfortable truth

4. ENDING
   - reflective, unresolved
   - should mentally loop back to hook
   - MUST NOT end with pure guilt overload

------------------------------------------------------------
LOOP SYSTEM
------------------------------------------------------------

Ending must make the viewer rethink the hook:
- creates replay
- feels incomplete in a satisfying way
-loops seemlessly to hook

------------------------------------------------------------
REJECTION FILTER
------------------------------------------------------------

Rewrite if:
- sounds like typical Islamic reminder
- feels like advice instead of exposure
- lacks tension progression
- does not sound natural aloud

------------------------------------------------------------
SAFETY RULES
------------------------------------------------------------

- No fake hadith/Quran
- No false rulings
- If unsure → phrase as reflection or just reject

------------------------------------------------------------
FINAL RULE
------------------------------------------------------------

The script must sound powerful when spoken.

If it feels safe, generic, or predictable → REWRITE.
